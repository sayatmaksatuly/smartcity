# Приватность и границы достоверности

- Геолокация запрашивается только кнопкой пользователя. Старт по умолчанию — точка карты, не определённое местоположение человека. Есть ручные координаты и клик по карте.
- Приложение не сохраняет GPS, запросы и историю чата на диск или в SQLite, не собирает аналитику. В памяти страницы живут старт, последние восемь сообщений чата и его структурированное состояние. Перезагрузка очищает их. Supabase Auth сохраняет сессию в браузере для входа после перезагрузки; на общем устройстве следует выйти. Пользователь по своему действию сохраняет отображаемое имя, предпочтения, OSM ID избранного и прогулок в PostgreSQL. Email хранится в Supabase Auth. GPS, transcript и геометрия маршрута в личные таблицы не передаются.
- Python backend не хранит auth-сессии. Access-log отключён в штатных командах; не включайте его на демонстрации. Произвольный сторонний proxy может иметь собственные логи. Удаление личных данных внутри профиля атомарно удаляет данные приложения через RLS, но не учётную запись Supabase Auth; удаление auth account требует защищённой административной процедуры.
- Google получает разобранные категории/интересы/ограничения и найденные POI при настроенном Gemini. Исходный пользовательский текст, упомянутый старт, точные координаты пользователя и телефонные данные POI не передаются. Контекст содержит расстояния до реальных POI, поэтому приблизительная область поиска может быть понятна провайдеру. Политики провайдера определяются командой и типом ключа.
- OSM получает стандартные запросы тайлов: IP, Referer и область карты. Шрифт включён локально, Google Fonts во время использования не запрашивается. Внешние ссылки открываются только пользователем.
- По действию «Маршрут» openrouteservice получает координаты подтверждённого старта и выбранных OSM-мест. В приложении они не кэшируются и не логируются. Сроки хранения внешним провайдером определяет его политика. Отсутствие ключа/пути/сети не заменяется прямой линией.
- Ключ хранится только на сервере (`backend/.env`/environment), исключён из Git, не возвращается API. Ошибки SDK намеренно не логируются целиком.

**Факты:** исходные OSM-имя/координаты/теги/источник/дата импорта. Это данные сообщества, не независимая проверка. Часы и цены могут устареть. В базе сохраняется и timestamp самой OSM-выгрузки.

**Оценки:** Haversine по прямой; время дороги с коэффициентом 1,3 и фиксированной скоростью; 15–45 минут на посещение. Река, заборы, входы, снег/ветер, светофоры, безопасность пути и доступность для маломобильных людей не учтены. На велосипеде не проверяется разрешённость проезда. Центр площадного объекта может быть далеко от входа. Это не навигация.

**Маршрут:** отдельный ответ ORS с пешеходной геометрией, дистанцией и приблизительным временем. ETA не гарантировано; маршрут зависит от актуальности OSM и привязки к дорожке (не более 250 м). Вход, ремонт, снег и фактическая проходимость требуют проверки на месте. Несколько результатов не становятся прогулкой автоматически: пользователь выбирает порядок, затем сервис проверяет суммарную дорогу и примерные посещения в бюджете. При повторном открытии сохранения геометрия запрашивается заново.

**Предложения:** действие в карточке — идея, не гарантия события/услуги. Нет рейтингов, выдуманных адресов, Wi-Fi без подтверждающего тега, обещаний тишины, столиков, розеток, групповой вместимости.

**AI:** JSON schema плюс независимая проверка ID, повторов, допустимых фрагментов и покрытия доступных основных интересов (до трёх категорий). Лишние поля ответа запрещены. Непроверяемый свободный текст модели не отображается. При сбое — явно не-ИИ режим. Простые отрицания и сочетания поддерживаются правилами; сложный контекст не гарантируется, предпочтительны явные фильтры.

**Чат:** контекст от браузера не считается доказательством фактов. Исторические POI и старт повторно проверяются по SQLite; возврат к прежним ID сохраняет текущие ограничения. Интерпретация реплик ограничена правилами, свободная беседа вне подбора мест недоступна. Gemini получает только структурированные намерения и кандидатов, а не transcript. Смена старта по названию требует явного подтверждения. Локальные уточнения/повторный выбор помечаются без ИИ. Подробности и результаты: [Phase 3](PHASE3_REPORT.md).
