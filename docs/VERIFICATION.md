## Исправление Gemini — 17 октября 2026

**Первопричина:** в установленном `google-genai 2.31.0` передача `response_schema=GeneratedPlan` преобразовывала Pydantic `extra="forbid"` в поле `additional_properties: false` внутри `generationConfig.responseSchema` (в корне и во вложенных рекомендациях). Gemini Developer API отвечал HTTP 400 `INVALID_ARGUMENT`: неизвестное поле `additional_properties` в `generation_config.response_schema`. Ошибка возникала в `generate_content`, до парсинга JSON и `validate_plan()`. Обычный SDK-запрос без такой схемы поэтому работал.

Исправление: `response_json_schema=GeneratedPlan.model_json_schema()`. Стандартное поле `additionalProperties: false`, ограничения количества элементов и вложенная схема передаются без ошибочного OpenAPI-преобразования. `GeneratedPlan.model_validate_json()` с `extra="forbid"` и все проверки grounding сохранены: только найденные SQLite POI, уникальные места, разрешённые причины/действия и покрытие доступных основных интересов.

Сервер различает стадии `call`, `parse`, `grounding`; безопасный пример записи:

```text
recommendation_generation_failed stage=call code=unsupported_schema_field http_status=400
```

Для вызова используются коды `provider_http_error`, `timeout`, `sdk_error`; для парсинга — `invalid_json`, `schema_invalid`, `empty_response`, `truncated_response`, `non_success_finish`, `blocked_response`, `response_parse_error`; для grounding — `unknown_poi`, `duplicate_poi`, `duplicate_place`, `unsupported_reason`, `duplicate_reason`, `invalid_activity`, `invalid_count`, `missing_interest`. Логи не содержат запросов, координат, ID выбранных мест, ключей, исходных ответов модели, SDK exception text или traceback. В HTTP-ответе сохранён `fallback_reason=generation_failed` и честный локальный fallback.

Основной backend на 8000 перезапущен с исправлением; frontend на 5173 остался запущен. Временный сервер 8002 остановлен после QA.

## Живые сценарии

Все ответы — `mode=local`, ключ не настроен. Результаты относятся к текущему снимку и времени проверки, не являются стабильными эталонами тестов.

| Сценарий | Результат | Общая оценка, мин |
|---|---|---|
| A: Mega, прогулка, 60 минут | NU Park; Японский сад; Аллея мира и согласия | 40; 42; 48 |
| B: центр, тихое кафе / отдых, 60 минут | CrepeCafe; Degirmen; Drinkit | 33; 33; 35 |
| C: центр, достопримечательности, 120 минут | Байтерек; Триумфальная арка Мангилик Ел; Памятник Шарлю Де Голлю | 17; 103; 79 |

В каждом результате сохранён источник OSM. Часы всех перечисленных вариантов неизвестны и так обозначены. Дорога — расстояние по прямой ×1,3, а не построенный маршрут. Для кафе нет обещаний тишины, розеток или свободных столов.

Для изменённых основных вторичных текстов рассчитан контраст: `#58634f` на бумажном фоне — 5,76:1, на активной карточке — 5,45:1; `#59665d` на бумаге — 5,48:1. Это проверка выбранных цветовых пар, не полный аудит доступности всех элементов.

Количество совпадает с README и последним import_run, база не изменялась. Дубликатов по правилу алиас + категория + 35 м: 0; расхождений с действующим классификатором: 0; некорректных ссылок: 0; координат вне bbox: 0. Это проверка технической согласованности, не подтверждение всех свойств на местности.

У 416 POI часы отсутствуют; у 56 расписание не входит в поддерживаемый синтаксис. В обоих случаях возвращается unknown. Только один объект имеет `fee=no`, поэтому бесплатный подбор может быть пустым — неизвестная цена не трактуется как бесплатность.

## Границы проверки

- Живой Gemini не вызывался: `backend/.env` проверен только на наличие непустого ключа, результат — ключ отсутствует. Секреты не выводились и не редактировались.
- 90 backend-тестов включают SDK-контракт, grounding, fallback, ru/en/kk, три demo-сценария и ограничения. Это не проверка доступности внешнего Gemini API.
- Offline E2E моделирует отказ тайлов и browser offline-сигнал; физическое отключение адаптера не выполнялось. Отказ backend проверяется отдельно.
- Остаются два внешних deprecation-предупреждения: Google SDK `_UnionGenericAlias` / будущий Python 3.17 и Starlette TestClient / httpx2. Playwright сообщает о NO_COLOR/FORCE_COLOR. Ошибок выполнения в итоговом прогоне нет.
- Нет новой проверки чистой установки на другом ПК, публичного развёртывания, маршрутов и фактической доступности заведений.
